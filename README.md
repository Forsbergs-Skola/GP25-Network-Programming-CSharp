Network Programming in C#

We are going to make C# applications communicate with services over the internet.

By the end of the lesson, you will have built a client that can:

GET data from an API
POST data to a server
Submit a game score
Retrieve a shared scoreboard

Then show the progression:

1. Cat Fact API
      ↓
   Learn GET

2. Webhook.site
      ↓
   Learn POST

3. Zapier
      ↓
   See what happens to our POST

4. Shared Scoreboard
      ↓
   POST game data

5. Shared Scoreboard
      ↓
   GET game data

6. Final Client
      ↓
   Put GET + POST together
